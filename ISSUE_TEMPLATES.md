# Issue templates

Copy the template that fits into a new GitHub issue (the same templates are installed in `.github/ISSUE_TEMPLATE/` so GitHub offers them automatically). Search existing issues first. **Security problems: do not open an issue – follow [SECURITY.md](SECURITY.md).**

---

## 🐞 Bug report

```markdown
**What happened?**
A clear description of the bug.

**Steps to reproduce**
1.
2.
3.

**What did you expect?**

**Screenshots / log**
Paste the error text (game log, Problems panel, or the terminal) and add screenshots if useful.

**Your setup**
- Vextra Studio version: (Settings → About, or the VERSION file)
- OS: (Windows 11 / macOS 15 / Ubuntu 24.04 …)
- Mode: Desktop app / Browser dev server
- Area: Web editor / Game editor (2D / 3D) / AI plugin / Store Export / Cloud / Other
- Hardware if relevant: GPU, microphone, camera, VR / AR device

**Does the game or project file help?**
Attach a small .vxgame or a minimal project that shows the problem (no private data).
```

---

## 💡 Feature request

```markdown
**What do you want to make easier?**
The problem or goal (not just the solution).

**Your idea**
How could Vextra Studio do it? Sketches are welcome.

**Alternatives you tried**

**Who would benefit?**
Beginners / web developers / 2D game makers / 3D game makers / plugin authors …

**Anything else?**
```

## 🧩 New block / engine request

```markdown
**Block or feature name**
**Category** (Triggers, Properties, Physics, Microphone, Camera, VR, AR, …)
**What should it do?** (inputs, outputs, parameters)
**A game that would use it**
```

## 📚 Documentation problem

```markdown
**What is wrong or missing?**
**Suggested wording** (optional)
```
